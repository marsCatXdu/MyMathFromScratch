# Week 2 — Linear Algebra Structure

## Purpose

This phase develops the structure behind span and linear systems: independence, basis, subspaces, rank, and null spaces.

## Five-day target

**Progress:** `░░░░░` — 0 of 5 sessions complete

At the finish line, you should be able to inspect a small matrix, determine its rank, find bases for its column space and null space, and use those structures to classify the solutions of $Ax=b$.
